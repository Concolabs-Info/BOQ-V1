Quanto Pre + Takeoff Scope + Floor + Ceiling + Roof verification
===============================================================

Release scope
-------------
- Current Quanto production repository retained as the base.
- Existing demo-derived UI retained as the visual/interaction contract.
- Production Takeoff Scope added for all 10 planned elements.
- Scope is deterministic and makes no AI/model call.
- One generic Scope API routes to separate element-specific Scope definitions.
- Scope manifests/questions/fact-set dependencies are persisted in PostgreSQL via migration 004.
- Existing Floor, Ceiling and Roof production analysis/editing APIs remain intact; their primary evidence selection now comes from Scope.
- Columns, Beams, Slab, Doors & Windows, Walls, Stairs & Ramps and Foundation have production Scope definitions ready for later Bind/Detect stages.
- Existing Dimension / Workbook / 3D layouts are unchanged; a compact Scope status panel is added below the tabs.

Scope implementation checks
---------------------------
- Scope reads only the frozen Pre Project Frame plus declared published fact sets.
- Exact viewport boxes, levels, scale, source revision and source transforms are retained in the Scope manifest.
- Typical Pre source viewports can apply to multiple confirmed storeys without being collapsed to only one level.
- Primary-source ambiguity becomes a named SINGLE_CHOICE question instead of a silent guess.
- Missing scale or source transform locks only the affected measurement source.
- Vertical evidence coverage is recorded per level/scope where the element requires it.
- Cross-element dependency status is recorded per affected scope; pending dependencies hold downstream facts but do not invent substitutes.
- Stairs & Ramps do not falsely require a stair/ramp plan on every building storey.
- Slab/Foundation/Roof source-role rules prevent unintended duplicate primary representations according to the Scope plan.
- A new frozen Pre frame version causes the older Scope manifest to become stale; old manifests remain audit history.

- Python compileall: PASS

- OpenAPI contract regenerated with the generic Scope endpoints

Environment-limited checks
--------------------------
- The source ZIP does not include the frontend dependency tree (`node_modules`). Registry installation was unavailable in the packaging environment, so a full Next.js typecheck/build could not be completed here.
- Run `npm install`, `npm run typecheck`, `npm run test:syntax`, and `npm run build` on the normal development machine/CI before deployment.
- Apply `database/schema/004_takeoff_scope.sql` (or run the migration script) before using Scope against an existing database.
