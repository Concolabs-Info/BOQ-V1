# Ceiling — 3D

Uses the shared shell in `../3d.md`. This file is only the defaults.

## Default chips

| Category | Start |
|---|---|
| Ceiling finishes | On, sharp |
| Walls | On, faded |
| Slabs | On, faded |
| Floor finishes | Off |
| Doors | Off |
| Windows | Off |
| Columns | Off |
| Beams | Off |
| Foundation | Off |

Colour starts on **Type** (C01 ≠ C02 ≠ C03).

Default storey is Typical when the job has one. Typical shows **one** representative storey unless they hit All.

Off storeys are hidden. No section box. No explode.

A zone in 3D is the same id as the polygon and the workbook row.

Look at the soffit. Not down at the floor finish.

## Not on this child

Do not draw zones or deducts here. Add, Remove, and Delete stay in Dimension.
