# Ceiling

Takeoff child. Same shell as Floor. Own first pass. Own polygons.

Ceiling is **finishes** to a soffit. Not the slab. Not Floor. Floor is not pasted in. The product finds soffits on its own.

Three views, this element only:

- `dimension.md` — plans, zones, families, add / remove, questions
- `workbook.md` — ceiling-finish quantity lines
- `3d.md` — what is locked for 3D on this child

Shared shells: `../views.md`, `../dimension.md`, `../workbook.md`, `../3d.md`.
