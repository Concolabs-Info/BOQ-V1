# Columns

Takeoff child. First on the frame path.

Columns is **RCC columns**. Counted on the plan. Sized by the mark on the sheet. Height comes from the **model** (top at the soffit they select). Ground includes the stalk down to the pad. The pad itself is Foundation.

Not the slab. Not beams. Not footings.

Three views, this element only:

- `dimension.md` — plans, boxes, families, questions
- `workbook.md` — column quantity lines
- `3d.md` — what is locked for 3D on this child

Shared shells: `../views.md`, `../dimension.md`, `../workbook.md`, `../3d.md`.
