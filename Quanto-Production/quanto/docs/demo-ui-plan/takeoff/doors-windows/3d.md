# Doors & Windows — 3D

Uses the shared shell in `../3d.md`. This file is only the defaults.

## Default chips

| Category | Start |
|---|---|
| Doors | On, sharp |
| Windows | On, sharp |
| Walls | On, faded |
| Slabs | Off |
| Columns | Off |
| Beams | Off |
| Foundation | Off |

Colour starts on **Type** (D1 ≠ D2 ≠ FW2).

Default storey is Typical when the job has one. Typical shows **one** representative storey unless they hit All.

Off storeys are hidden. No section box. No explode.

## Not on this child

Do not draw openings here. Add and delete stay in Dimension.
