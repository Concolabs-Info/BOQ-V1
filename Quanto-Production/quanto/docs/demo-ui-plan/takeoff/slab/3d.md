# Slab — 3D

Uses the shared shell in `../3d.md`. This file is only the defaults.

## Default chips

| Category | Start |
|---|---|
| Slabs | On, sharp |
| Beams | On, faded |
| Columns | On, faded |
| Walls | Off |
| Doors | Off |
| Windows | Off |
| Floor finishes | Off |
| Ceiling finishes | Off |
| Foundation | Off |

Colour starts on **Type**.

Default storey is Typical when the job has one. Typical shows **one** representative storey unless they hit All.

Off storeys are hidden. No section box. No explode.

A plate in 3D is the same id as the polygon and the workbook row. Through-beam deducts are missing volume, not a second mesh.

## Section billboards

Uses the shared dropdown, bottom-right. Off until they pick a section.

On this child they pick A-A or B-B to read thickness, a step, or a trough against the real sheet.

## Not on this child

Do not draw plates, voids, or section lines here. Add, Remove, and thickness edits stay in Dimension.
