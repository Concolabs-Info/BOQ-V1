## Tree

```text
Doors
  D1
    Ground
    Typical 2nd–7th
    Terrace
  D2
    …
Windows
  FW2
    Typical 2nd–7th
  …
```

Family → floor. Typical is one child with a factor. Types that only exist on Ground have no typical child.

## Grid

Same shared columns. Unit is **nr**.

Calc example: `12 × 6 = 72`.

Scope examples: `Ground`, `Typical 2nd–7th`, `Terrace`.

Qty is edited in the grid. Save, then Confirm again.

Footer always both totals. Example: `Showing 72 of 216 nr`.
