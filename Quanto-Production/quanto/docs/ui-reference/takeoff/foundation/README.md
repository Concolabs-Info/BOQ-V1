# Foundation

Takeoff child. Last in the list. Own first pass.

Not: reinforcement quantity, tests, rig hours, disposal, cut-off, bored-but-empty length, column stalk, ground slab.

If the backend sends nothing, this child **stays listed**. Empty. Not found. No invented grid.
