# Stairs & Ramps — 3D

Uses the shared shell in `../3d.md`. This file is only the defaults.

## Default chips

| Category | Start |
|---|---|
| Stairs / ramps | On, sharp |
| Slabs | On, faded |
| Walls | On, faded |
| Columns | Off |
| Beams | Off |
| Doors | Off |
| Windows | Off |
| Floor finishes | Off |
| Ceiling finishes | Off |
| Foundation | Off |

Colour starts on **Type**. Balustrades do not get their own colour mode. They ride the open edge.

Default storey is Typical when the job has one. Typical shows **one** representative storey unless they hit All.

Off storeys are hidden. No section box. No explode.

A flight that passes through a storey stays visible when that storey is on. Same id as the outline and the workbook row.

A ramp mesh appears only if that family exists.

## Section billboards

Uses the shared dropdown, bottom-right. Off until they pick a section.

On this child they pick A-A or B-B to read rise, waist, and the dog-leg against the real sheet.

## Not on this child

Do not draw flights, voids, or rail edges here. Add, Remove, and edge picks stay in Dimension.
