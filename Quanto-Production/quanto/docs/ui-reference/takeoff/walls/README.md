# Walls

Takeoff child. Last on the skin path. Wants Doors & Windows for deducts and Columns for snaps.

Walls is **masonry and the coats on its faces**. Not the slab. Not Floor. Not Ceiling. One centerline. Two workbook parents: **Walls** and **Finishes**. Finishes are not a second draw.

Three views, this element only:

- `dimension.md` — plans, centerlines, families, split / merge, questions
- `workbook.md` — masonry and wall-finish quantity lines
- `3d.md` — what is locked for 3D on this child
