# 3D — shared shell

The model view for one Takeoff child. Same chrome for Doors, Walls, Columns. Which categories start sharp, faded, or off belongs to the element.

Review, not authoring. Chat does not live here.

## Happy path

1. The user opens a Takeoff child and chooses **3D**.
2. The model fills the center. This child’s elements are sharp. Hosts are faded. The rest is off.
3. They step storey by storey, or open Typical as one group, or show All.
4. They can pick a **section billboard** from a dropdown at the bottom-right of the canvas: the real section sheet, stood up 90° on its cut line on the plan.
5. They click an element. Item shows that instance. Same id as Dimension and Workbook.
6. **Show on plan** opens Dimension. **Show in workbook** opens Workbook.

## Layout

Two panes. No left tree.

```text
┌────────────────────────────────────┬──────────┐
│                                    │ Item     │
│         model (~80%)               │ family   │
│  storey · category · colour        │ H × W    │
│                    [ Section ▾ ]   │ source   │
└────────────────────────────────────┴──────────┘
```

## Center pane

The Three.js model. Same instances as Dimension and Workbook.

Visibility sits on the canvas, not in a pane.

### Storeys

Stepper plus chips. Not a fifty-row list.

```text
‹   Typical 2–7   ›     All     Foundation
```

| Control | Does |
|---|---|
| ‹ › | One storey, or the next Typical group |
| Typical | One group, same as Workbook. Shows **one** representative storey unless they hit All |
| All | Whole stack |
| Foundation / Roof | Own chips. Not a floor among 1…50 |
| All floors… | Opens the full list when the job is tall |

Any set of storeys can be on. Default is the child’s usual scope (Typical if this job has one).

A storey that is off is **hidden**, not clipped. No section box in this demo. No explode.

### Section billboards

Not a section box. Not a clip. The cropped section viewport from Pre → Plans, stood up **90°** on the cut that is already drawn on the floor plan. The sheet itself sits in space.

Control: a **dropdown**, bottom-right of the canvas. Same corner idea as the Dimension minimap. Not a chip in the storey row.

```text
Section ▾
  Off
  A-A
  B-B
```

| Control | Does |
|---|---|
| Off | No billboard. Default on every child |
| A-A / B-B / … | Stands that sheet up on its cut. One at a time |

Review only. No draw on the billboard. No tracing a roof pitch here. Confirm of height stays in Pre, or on a wall or upstand override.

If the crop is short of the cut, alignment is not decided. Do not invent a gizmo.

Apartments rarely need this. Roof, parapets, mezzanines, and later pitched houses do. The dropdown lives on every child.

A column that passes through a storey stays visible when that storey is on. A door lives on one storey.

### Categories

Chips on the canvas.

```text
Doors   Windows   Walls   Slabs   Columns   Beams   Foundation
```

On this child: this child’s categories are **on and sharp**. Hosts are **on and faded**. The rest is **off** until the user turns them on.

The element file names the default chips.

**Isolate** is a verb, not a chip: this type, or this selection. Temporary. Reset clears it.

### Colour

One mode at a time. Colour paints **this child’s** elements only. Ghosted hosts stay grey.

| Mode | Does |
|---|---|
| Type | Each family a colour. Default inside a child |
| Status | Confirmed / needs input / missing |
| Category | Doors vs walls vs columns. For a whole-model read |
| Consistent | One material. Selection pops |

### Camera

Orbit, pan, zoom with the mouse. View cube, top-right. Fit frames what is visible.

No Draw. No Measure. Add and delete stay in Dimension.

## Right pane — Item

Same component as Dimension’s Item tab. Thin. Always on.

- Nothing selected: the view — which storeys are on, colour mode
- One pick: family, mark, height, width, floor, source
- Many picks, same family: count and the combined quantity for that selection
- Many picks, mixed families: count and *varies*. No invented family

A combined number is a readout. It is not a confirm. Confirm is Workbook.

**Show on plan** / **Show in workbook**.

## Buttons and controls

| Control | What it does |
|---|---|
| Storey stepper | Moves one storey or Typical group |
| All | Whole stack |
| Foundation / Roof | Toggles that chip |
| Section dropdown | Bottom-right. Off, or one section sheet. Off by default |
| Category chip | On / faded / off |
| Isolate | This type or this selection |
| Colour | Type, Status, Category, Consistent |
| View cube / Fit | Camera |
| Click | Selects that instance |
| Show on plan | Opens Dimension on that instance |
| Show in workbook | Opens Workbook on that line |

## What the user can do

- Walk floor by floor on a tall job without a long list
- See Typical as one group
- Turn hosts on faded, and other categories on if they need them
- Colour by type or by status
- Stand a section sheet on its cut line and read height or a pitch against the model
- Read the selected instance without leaving the model

## What the user cannot do here

- Draw, add, or delete. That is Dimension.
- Confirm a quantity line. That is Workbook.
- See chat.
- Write a quantity by selecting meshes.
