# Roof

Takeoff child. Covering and waterproofing. Own first pass. Own polygons.

Roof is **not** the structural plate. That is Takeoff → Slab. Terrace tiles (F10) and trough build-up (F12) stay in Floor. Parapet masonry (M06) stays in Walls. Wet-area tanking is not in this child.

Two workbook parents: **Coverings** and **Upstands**. Upstands ride the covering perimeter. They are not a second draw.

Three views, this element only:

- `dimension.md` — plans, sections, covering zones, upstand edges, questions
- `workbook.md` — covering and upstand quantity lines
- `3d.md` — what is locked for 3D on this child

Shared shells: `../views.md`, `../dimension.md`, `../workbook.md`, `../3d.md`.
