# Beams — 3D

Uses the shared shell in `../3d.md`. This file is only the defaults.

## Default chips

| Category | Start |
|---|---|
| Beams | On, sharp |
| Columns | On, faded |
| Slabs | On, faded |
| Walls | Off |
| Doors | Off |
| Windows | Off |
| Floor finishes | Off |
| Ceiling finishes | Off |
| Foundation | Off |

Colour starts on **Type**. Kind does not get its own colour mode. Through vs downstand is on Item.

Default storey is Typical when the job has one. Typical shows **one** representative storey unless they hit All.

Off storeys are hidden. No section box. No explode.

A run in 3D is the same id as the centerline and the workbook row.

## Section billboards

Uses the shared dropdown, bottom-right. Off until they pick a section.

On this child they pick A-A or B-B to read drop vs through against the real sheet.

## Not on this child

Do not draw runs, split, or merge here. Add, Split, Merge, and Delete stay in Dimension.
