# Beams

Takeoff child. Second on the frame path. After Columns. Before Slab.

Beams is **RCC beams**. A centerline on the plan. Closest twin is Walls.

Two kinds. **Downstand** hangs under the soffit — extra-over only. **Through** occupies the plate — Slab deducts that strip. Kind lives on the run. The family is the size (or the mark on the sheet).

Not the slab. Not columns. Not footings.

Three views, this element only:

- `dimension.md` — plans, centerlines, kind, split / merge, questions
- `workbook.md` — beam quantity lines
- `3d.md` — what is locked for 3D on this child

Shared shells: `../views.md`, `../dimension.md`, `../workbook.md`, `../3d.md`.
