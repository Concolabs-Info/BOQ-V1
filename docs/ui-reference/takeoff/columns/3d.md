# Columns — 3D

Uses the shared shell in `../3d.md`. This file is only the defaults.

## Default chips

| Category | Start |
|---|---|
| Columns | On, sharp |
| Slabs | On, faded |
| Beams | On, faded |
| Walls | On, faded |
| Doors | Off |
| Windows | Off |
| Floor finishes | Off |
| Ceiling finishes | Off |
| Foundation | Off |

Colour starts on **Type**.

Default storey is Typical when the job has one. Typical shows **one** representative storey unless they hit All.

Off storeys are hidden. No section box. No explode.

A column that passes through a storey stays visible when that storey is on. Same id as the box and the workbook row.

Height in the model is the same pick as Item: top at the soffit, Ground down to the pad.

## Section billboards

Uses the shared dropdown, bottom-right. Off until they pick a section.

On this child they pick A-A or B-B for a transfer, a drop, or a roof stub.

## Not on this child

Do not draw columns here. Add and Delete stay in Dimension.
