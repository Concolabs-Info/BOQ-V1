# Foundation — 3D

Uses the shared shell in `../3d.md`. This file is only the defaults.

## Default chips

| Category | Start |
|---|---|
| Foundation (piles + caps) | On, sharp |
| Columns | On, faded |
| Slabs | Off |
| Walls | Off |
| Beams | Off |
| Doors | Off |
| Windows | Off |
| Floor finishes | Off |
| Ceiling finishes | Off |

Colour starts on **Type**.

Default storey is the **Foundation** chip, not Typical.

Off storeys are hidden. No section box. No explode.

A pile or cap in 3D is the same id as the mark / box and the workbook row.

Empty job: no pile meshes. The child still opens. Item says the view.

## Section billboards

Uses the shared dropdown, bottom-right. Off until they pick a section.

On this child they pick A-A or B-B to read commencing level, toe, or cap thickness against the real sheet.

## Not on this child

Do not draw piles or caps here. Add and Delete stay in Dimension.
