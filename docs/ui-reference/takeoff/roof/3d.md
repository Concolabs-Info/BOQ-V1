# Roof — 3D

Uses the shared shell in `../3d.md`. This file is only the defaults.

## Default chips

| Category | Start |
|---|---|
| Roof coverings | On, sharp |
| Walls | On, faded |
| Slabs | On, faded |
| Floor finishes | Off |
| Ceiling finishes | Off |
| Doors | Off |
| Windows | Off |
| Columns | Off |
| Beams | Off |
| Foundation | Off |

Colour starts on **Type** (R01 ≠ R03). Upstands do not get their own colour mode. They ride the covering edge.

Default storey is **Roof / Terrace**, not Typical. Upper roof is its own chip next to it.

Off storeys are hidden. No section box. No explode.

A zone in 3D is the same id as the polygon and the Coverings workbook row.

## Section billboards

Uses the shared control: a **dropdown**, bottom-right of the canvas. Off until they pick a section.

On this child they pick A-A or B-B to read upstand height, a tank step, or (later) a pitch against the real sheet.

Not on by default. The dropdown is still there so they do not hunt for a chip.

## Not on this child

Do not draw zones, deducts, or upstand edges here. Add, Remove, and edge picks stay in Dimension.
