# Slab

Takeoff child. Structural plate. Used to live in Pre. It is measured work, so it sits here.

Slab is **in-situ concrete**, not Floor finishes. Not Roof. Not Pre.

Columns and Beams come first. Through-beams already taken off are deducted from the plate. Downstands are not. They stay extra-over on Beams.

Three views, this element only:

- `dimension.md` — plan plate, section thickness, through-beam deducts, questions
- `workbook.md` — slab quantity lines
- `3d.md` — what is locked for 3D on this child

Shared shells: `../views.md`, `../dimension.md`, `../workbook.md`, `../3d.md`.
