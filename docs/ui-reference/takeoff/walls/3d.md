# Walls — 3D

Uses the shared shell in `../3d.md`. This file is only the defaults.

## Default chips

| Category | Start |
|---|---|
| Walls | On, sharp |
| Doors | On, faded |
| Windows | On, faded |
| Slabs | On, faded |
| Floor finishes | Off |
| Ceiling finishes | Off |
| Columns | Off |
| Beams | Off |
| Foundation | Off |

Colour starts on **Type** (M01 ≠ M03 ≠ M06). Finishes do not get their own colour mode. They ride the wall.

Default storey is Typical when the job has one. Typical shows **one** representative storey unless they hit All.

Off storeys are hidden. No section box. No explode.

A run in 3D is the same id as the centerline and the Walls workbook row.

## Section billboards

Uses the shared dropdown, bottom-right. Off until they pick a section.

On this child they pick A-A or B-B for parapet height, mezzanine height, and any storey the plan cannot show.

## Not on this child

Do not draw runs, split, or merge here. Add, Split, Merge, and Delete stay in Dimension.
