# Rate Dropdown Delete and Expand UI

## Summary
Rate Files improve grouped table expansion and reusable dropdown management. Main item groups use a chevron expand control, and reusable dropdown values can be deleted directly inside dropdown lists without changing existing saved rate rows.

## Key Changes
- Replace the main-item table `+ / -` expand control with an accessible chevron button.
- Add delete actions for project reusable dropdown values.
- Add delete actions for Material attribute names and Material attribute values.
- Preserve existing saved `rate_item` text when catalog values are deleted.
- Hide deleted default rate options per project so default unit values do not immediately reappear.
